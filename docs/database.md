# قاعدة البيانات — المرحلة الثالثة

ملفات الهجرة في `supabase/migrations` تُطبَّق بالترتيب:

| الملف | المحتوى |
|---|---|
| 0001 | المستخدمون، ملفات الطلاب والمعلمين، الأدوار والصلاحيات (دور × نطاق) |
| 0002 | البرامج، نسخ الإعدادات بتاريخ سريان، الكتب والمجلدات، الخطط والمراحل |
| 0003 | التقديم، التسجيلات، إسناد المعلمين، استثناءات الطالب، التقويم |
| 0004 | الرصد اليومي (لا حذف، استبدال فقط)، الاستئذان، الانضباط، المتابعة، حالة اليوم المحسوبة |
| 0005 | الفترات والحجوزات (منع تجاوز السعة)، الاختبارات، تقدّم المراحل |
| 0006 | الإشعارات (مفتاح فريد يمنع التكرار)، الإعلانات، الشكاوى، سجل الإجراءات، الاستيراد، لقطات التقارير |
| 0007 | سياسات أمان الصفوف (RLS) والدوال المساعدة في المخطط `app` |
| 0008 | نقل الإضافات إلى المخطط `extensions` |

## قواعد ثابتة في البنية
- لا قيمة لائحية في الكود: القواعد في `program_settings_versions.settings`، والنسخة المعتمدة لا تُعدَّل.
- سجل الرصد لا يُحذف ولا يُعدَّل محتواه؛ التصحيح بسجل جديد و`superseded_by`.
- التعويض يُحسب في يوم أدائه (`credited_date`) ويرتبط باليوم الفائت (`makes_up_date`).
- الوحدات رقمية بكسور (نصف حديث / نصف صفحة).
- رقم الإثبات مشفّر ولا يُقرأ من المتصفح إطلاقًا.
- الكتابات الحساسة تمر عبر دوال الخادم؛ المتصفح يكتب مباشرة فقط: إعدادات البرامج (بصلاحية)، اشتراكات الإشعارات، قراءة الإشعار، الاستئذان، الشكوى.

## اختبارات أُجريت على البيئة التجريبية (داخل معاملة أُلغيت)
منع تعديل/حذف الرصد، منع سجلين فعّالين لليوم، الاستبدال المشروع، تعويض ليوم لاحق مرفوض، تجاوز سعة الفترة مرفوض،
قفل الإعدادات المعتمدة، منع تكرار الإشعار، سجل تاريخ الحالة، تفرّد البريد بغض النظر عن حالة الأحرف،
وRLS: الطالب يرى تسجيله فقط ولا يرى رقم الإثبات ولا يكتب الرصد، المعلم يرى طلابه فقط، المجهول ممنوع.
